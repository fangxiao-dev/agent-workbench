# Decision Policy

Ask the owner only when evidence supports two or more materially different valid outcomes. Implementation detail, formatting, mechanical consistency and a uniquely implied contract outcome are reviewer recommendations, not owner decisions.

For each decision provide: the question, viable options, consequences, recommendation and default if the owner declines to choose. Once answered, apply it to every affected section in one closure batch.

每一 wave 只向 owner 提交会改变方案结果的最小决策集合。机械一致性、唯一可推导的修正和纯编辑问题由 reviewer 给出确定建议；owner decision 后以 affected-scope closure verification 收口。

# Plan Review Rubric

## Confirmed preferences

- Preserve only review facts that change the verdict or next action.
- Same-session unchanged candidates need no extra persistence; cross-session reuse names the reviewed Git commit.
- Apply means edit the explicitly accepted files and validate them, with Git providing history.
- Report material findings separately from editorial suggestions.
- Escalate to the owner only for genuine product/authority choices.

## Superseded preferences

- Earlier audit-heavy review recovery and binding records are retired by the current lightweight workflow.

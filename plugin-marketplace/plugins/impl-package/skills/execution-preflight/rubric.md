# Execution Preflight Rubric

## Confirmed preferences

- Check worktree, branch, HEAD commit, package, initial bundle final approval, write-set, dirty conflicts and external mutation authority.
- Apply the initial bundle approval to all later updates within the same package as the single approval gate.
- Use the existing package records and Git commit as the freshness boundary.
- READY authorizes the named next action and ordinary package bookkeeping; push, merge, release and external mutation use their independent authorization paths.

# 交互式 HTML 输出

## 何时用

HTML 只用于决策模式（固定选项）；发现模式一律用 Markdown。决策模式里：

- 收件人自己填、题目较多或分两部分时，用 HTML；
- 当面一起填、或题目很少时，用 Markdown（写法见 `decision-mode.md`）。

## 怎么做

1. 复制 [`../assets/decision-questionnaire.html`](../assets/decision-questionnaire.html)，命名为 `<主题>-问卷.html`（或 `to-questionnaire-<slug>.html`），放在问卷所属项目的调研目录。
2. 只改文件里标“只改这一段”的 `CONFIG` 与 `DATA`：
   - `CONFIG.title`：页面标题，也是导出第一行。
   - `CONFIG.storeKey`：localStorage 键。浏览器直接打开本地文件时，同一浏览器里所有本地文件共享 localStorage，所以键必须每份问卷唯一；**改版时不要改**，否则对方已填的答复读不回来。不要在键里带版本号。
   - `CONFIG.exportFilePrefix`、`CONFIG.intro`（说明区段落：选项含义、先答哪部分、怎么发回）。
   - `CONFIG.legacyChoices`：可省；只有改过选项值时才写“旧值 → 新值”。
   - `CONFIG.ui`：全部界面文字，默认中文；换语言时整体替换。
   - `DATA`：按章节组织，章节 `title` 只写主题（编号由页面生成）；`later: true` 归入第二部分并放在最后。每题 `id`、`source`（来源条目）、`q`、`desc`、`rec`，可选 `flag: true`、`from: [旧题号]`。
3. 引擎部分不改。它已提供：左侧固定章节导航（窄屏变横向）、全部 / 未回答 / 已回答筛选（正在操作的卡片不会被立刻筛掉，焦点离开或切换视图后才按筛选隐藏）、再点取消、空白意见不算、本机自动保存、合并题显示旧答复、导出 `.txt` 与复制答复（每行带题号与来源，删除题的旧答复附在末尾、空白意见不计）、无外部依赖、浏览器直接打开。
4. 发出前自己在浏览器里点一遍：选、取消、写意见、切换筛选、导出。

## 交付说明（写给收件人）

- 用电脑浏览器直接打开文件即可，不需要登录。
- 答复只存在这台设备的这个浏览器里；请在同一台设备答完，再点“导出答复”或“复制答复”发回。

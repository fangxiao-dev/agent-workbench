Impl-Package：保留流程，减少审计负担

Decision/Spec 定义行为，Plan/Ticket/DAG 定义交付方式，State/Progress 支持恢复，Gate 与 Backfill 完成收口。D/S/P 只是可读别名，Git commit ID 是唯一版本锚点。

1. Align

Decision → Spec；按实际影响升级，并保留未受影响范围。

2. Plan

选择 Composition，完成 Coverage、Verification、Ticket/DAG joint validation。

3. Activate

init 发布 bundle，创建 state、Progress 与 Attempt Execution Record。

4. Execute

CAS 更新状态；Progress 是统一入口，checkpoint/judgment 进入 Execution Record。

5. Gate

blocked 可恢复；pass/fail/defer 冻结 Attempt，后续工作进入 patch。

6. Backfill

消费 pending durable delta，核对 target reachability，经 owner 批准后写入稳定文档。

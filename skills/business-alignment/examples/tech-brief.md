# 技术对齐文模板

给技术人员或另一个 agent。Markdown，对方直接在文件里作答或照着做；不要界面示意、本机保存、导出，不做收件人视角审阅（对方会追问）。

```markdown
# <主题>：对齐

**目的：** 回来后要定下什么。　**来源：** <规则 / Spec / 任务路径>

## 已定（照做，不用回答）

- <结论>，依据 <路径或决定>。

## 待你确认

### T-01 <一个决定一题>
现状：<一两句>。推荐：<具体值>。
> 答：同意 / 不同意，因为 …

## 请你查

### R-01 <需要查证的事实>
从哪查：<路径、命令、系统>。回答格式：<数字 / 是否 / 列表>。
> 答：

## 还有什么我们没问到的？
```

题号规则同 `blocks.md`：稳定、对应来源、永不复用。

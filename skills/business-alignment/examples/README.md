# 范式

| 文件 | 范式 | 默认用于 |
|---|---|---|
| `deck.html` | 翻页讲解：左侧目录，每页左图右解说，底部本页意见，可插确认项 | 探索、汇报；讲解中夹少量拍板 |
| `questionnaire.html` | 单页问卷：按章列题，每题推荐 + 四个固定选项，筛选未答，改版迁移 | 拍板（题多、对方独自填） |
| `tech-brief.md` | Markdown 对齐文：已定 / 待你确认 / 请你查 | 技术对齐 |
| `blocks.md` | 公共约定与积木目录 | 所有 HTML |

用法：复制范式文件到项目的对齐目录（例如 `output/business-alignment/对齐-<主题>_<yymmdd>.html`），只改内容区和 `CONFIG`，脚本引擎不改。`questionnaire.html` 只改标「只改这一段」的 `CONFIG` 与 `DATA`。发出前在浏览器里点一遍：意见、选择、翻页、导出、清空。

## 来源

- `questionnaire.html`：原 to-questionnaire 决策问卷（2026-11 前）。
- `deck.html`：2026-11-22 合并两份对齐——「税务所邀请企业」（探索两轮：确认项、上次已确认、情况切换、重置、按页 id 存意见、题号重编换键）与「账号重置密码」（汇报：总览放首页、左侧目录、每页意见、全局导出）。

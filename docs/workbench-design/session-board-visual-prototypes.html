Session 看板 · 三个视觉方向

同一组会话数据、同样的列与状态，只有视觉语言不同。这版原型先定方向，不做交互。

A · Airy Minimal冷白、无泳道、留白分列；卡片是唯一实体表面，线细影淡

视觉重心落在标题上：状态用 13px 环形图标，待办是一条安静的灰琥珀文字，时间退到右上角。

B · Soft Glass淡青环境色、半透明托盘、柔和景深；托盘只包住内容，不拉满高度

玻璃只出现在浮层与列托盘，卡片仍是实体白，避免整屏半透明导致的发灰。

C · Compact ProLinear 式高密度：列表行 + 发丝分隔，只有悬停才出现表面

一屏能读到的会话最多；代价是行与行的边界靠对齐和节奏维持，不适合很长的摘要。
